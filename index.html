Hatchmark Charts for Excel

Business charts with ISO 24896-aligned notation — actuals solid, forecasts hatched, plan outlined, variances coloured by business impact — rendered straight from your worksheet data, and kept up to date as it changes.

AC — solid FC — hatched PL/BU — outlined good bad

Install

Mac (Excel for Microsoft 365)

Download Mac installer
  1. Download, then right-click the file ▸ Open (first run only — macOS gate for downloaded scripts), and confirm.
  2. Quit and reopen Excel.
  3. Look for the Hatchmark tab in the ribbon.

Windows (Excel for Microsoft 365)

Download Windows installer
  1. Right-click the downloaded file ▸ Run with PowerShell (if it reports a sharing error, run PowerShell as administrator and try again).
  2. Restart Excel ▸ Insert ▸ My Add-ins ▸ Shared Folder ▸ Hatchmark Charts.
  3. From then on it lives on the Hatchmark ribbon tab: Open Hatchmark and Insert chart for making charts, Check workbook and Refresh all for keeping them right.

Excel on the web (nothing to install)

Download manifest file
  1. Open your workbook at excel.cloud.microsoft.
  2. Insert ▸ Add-ins ▸ More Add-ins ▸ My Add-ins ▸ Upload My Add-in and choose the downloaded manifest.

Use it

  1. Lay out your data with period labels across the top and one row per scenario, first cell the code: AC actual · FC forecast · PL plan · BU budget · PY last year. Blank cell = no value. (Sideways — scenarios across the top — works too.)
  2. Select the whole block, then use the Hatchmark tab: Insert chart makes one straight away, or Open Hatchmark ▸ Load selection to choose a type first.
  3. Pick a chart type, check the preview, Insert chart.
  4. Edit your numbers — the chart updates itself while the add-in is running. The pane's Insert example data button sets up a working example in one click.

Inserted charts are ordinary pictures: colleagues without the add-in see and print them exactly as rendered.

If something looks off

An "add-in error" banner usually clears with a full Excel restart. Charts inserted by very old versions of the pane don't auto-update — delete and re-insert them. Questions: ask your course instructor.
